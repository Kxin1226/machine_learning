## 3. 实验过程

### 3.1 算法原理

#### K-means 算法步骤
K-means 是一种基于距离的聚类算法，其基本思想是：

1. **初始化**: 随机选择 k 个样本作为初始聚类中心
2. **分配步骤**: 将每个样本分配到距离最近的聚类中心，形成 k 个簇
3. **更新步骤**: 重新计算每个簇的中心（簇内所有样本的均值）
4. **迭代**: 重复步骤 2-3，直到聚类中心不再变化或达到最大迭代次数

#### K-means++ 改进
K-means++ 是对初始化步骤的改进：
1. 随机选择第一个聚类中心
2. 对于每个后续中心，以距离的平方为权重随机选择
3. 这样使初始中心尽可能分散，减少陷入局部最优的可能性

```
KMeans 类主要属性:
- n_clusters: 簇的数量
- cluster_centers_: 聚类中心坐标
- labels_: 每个样本的簇标签
- inertia_: 簇内平方和
- n_iter_: 收敛所需的迭代次数
```
